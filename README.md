A program that writes a one-line museum placard for an ordinary office keyboard, treated as an ancient artifact dug from a lost civilisation. It scores sixteen candidate placards against the judge's published brief — inventive conceit first, then dryness of wit, economy, and label craft — plus the results of a local proxy tournament (the same brief, head-to-head, both orders), and writes the winner to `/output/entry.txt`. Deterministic: no network, no randomness, no input.

The winning placard (129 characters):

> Keyboard, c. 2017. Plastic, crumbs. Excavated from a desk drawer; scholars believe its missing keys spell a forgotten god's name.

## Run it

```sh
python3 main.py  # writes /output/entry.txt
```
